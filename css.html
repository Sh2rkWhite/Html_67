Каскадні таблиці стилю

Частково про CSS зазначалось у попередньому модулі

Реокмендованний спосіб додавати стиль для всього сайту- це окремий файл що підключаеться за допомогаю тегу link у заголовку сторінки.Суть файлу - послідовне застосування стилів для груп елеменетів які потрапляють до селекторів. Можно сказати що кожна команда CSS-файлу маэ структуру. 

        Знайти все що відповідає такому-то селектору {
        і застосувати
        до нього данний
        набір стилів
        }

Термін каскадний стверджує те що кожна наступна команда буде поєнуватися з попереднім.

Основні селектори

СелекторЗначення
* Всі єлементи
img Всі елементи що мають тег <img />
.middle Всі єлементи в яких зазначенно class="middle"
.selecter-table th Всі єлементи <th> які знаходяться в середині в яких зазначенно class="selecter-table" Наприклаж "p b" -всі теги <b> в середині параграфів (<p>); ".bold .small" - всі елементи з класом "small" в середині елементів з класом "bold "
p,b Кома означає та - отже спільний стиль для двох селекторів
